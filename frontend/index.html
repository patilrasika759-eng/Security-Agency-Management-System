Common questions / सामान्य प्रश्न

Quick answers about how the system works.

Who can approve payroll?

Only the Admin / Owner role. Staff can prepare records but cannot finalize financial transactions.

Can a client see other clients' data?

No. A client should see only the guards, incidents and invoices for their own sites. Enforce this in the backend.

Is the GPS check-in real?

This frontend demonstrates the workflow. Real device GPS and server validation must be added separately.

Can a finalized invoice be deleted?

In the intended system, finalized invoices are locked and changes should remain traceable.
